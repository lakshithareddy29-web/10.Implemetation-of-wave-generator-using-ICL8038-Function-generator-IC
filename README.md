# 10.Implemetation-of-wave-generator-using-ICL8038-Function-generator-IC
**Aim:**
To Simulate Triangular-wave-generator using Op-amp

**SOFTWARE REQUIRED:**
 Proteus

**PROCEDURE:**
Open Proteus software.
Create a new schematic design.
Select and place the required components from the library.
Place the ICL8038 function generator IC, resistors, capacitor, power supply and oscilloscope.
Draw the circuit and complete all the required connections.
Connect the output of the ICL8038 to the oscilloscope.
Save the circuit with a suitable file name.
Click on the Run Simulation option.
Observe the output waveform on the oscilloscope.
Verify the triangular waveform at the output.
